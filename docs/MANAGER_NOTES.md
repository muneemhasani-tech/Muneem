# Manager notes for the daily scout (fallback copy)

The weekly manager writes the live notes to Google Drive as `manager-notes-YYYY-MM-DD.md` in the folder
"MRA Property Scout"; the scout reads the newest one. This repo file is only the fallback.

Last updated: 2026-11-20.

## Rules for the scout
1. Report only: the one-line summary, the 3 calls (copied exactly), 5 other listings, problems. No extra commentary.
2. Memory lives in Drive (`seen-*.tsv`). Read the newest before the run and save today's after it.
3. A price under 5 lakh on a portal page is a placeholder; treat it as "price missing", never as a lead's price.
4. Never open Facebook or Google pages. Never commit anything to the repo.
