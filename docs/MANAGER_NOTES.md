# Manager notes for the daily scout

Written by the weekly manager review and read by the daily scout at the start of each run. Short on purpose:
every line costs tokens every day. Nothing here may ask the scout to contact anyone or push anything.

Last reviewed: 2026-11-18 (first review, set up by hand).

## Rules for the scout
1. Report only: the one-line summary, the 3 calls (copied exactly), 5 other listings, problems. No extra commentary.
2. A search that returns 0 results two days running goes under Problems with its query text, so the manager can retire it.
3. Memory: if Google Drive tools exist, read and write `seen-*.tsv`. If not, say "no memory" once and use `--fresh`.
4. Never open Facebook or Google pages. Never commit anything to the repo.
